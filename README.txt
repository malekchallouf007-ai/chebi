POÉSIE AI — Projet interactif
================================

Fichiers :
- index.html
- style.css
- script.js
- qr-poesie-ai.png

Fonctions :
- Design responsive
- Photos réelles via Wikimedia Commons
- Scanner IA simulé pour démonstration scolaire
- Expérience interactive par thèmes
- Assistant IA simulé
- QR Code prêt pour : https://malekchallouf007-ai.github.io/poesie-ai/

Publication GitHub Pages :
1. Crée un dépôt nommé `poesie-ai`.
2. Upload ces 4 fichiers à la racine.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Le QR Code sera alors cohérent avec l'URL prévue.

Note :
Le Scanner et l'Assistant sont des prototypes front-end. Une vraie analyse IA nécessite un modèle/API côté serveur.
